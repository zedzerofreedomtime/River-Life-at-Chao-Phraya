# UNICORN CRUISE — โมเดล Blender และการเลือกเก้าอี้ 3D

มุมมอง 3D เป็นอีกวิธีเลือกที่นั่งในระบบจองเดิม ใช้รหัสโต๊ะ เก้าอี้ ราคา และสถานะว่างจากรายการเดียวกับผัง 2D ไม่มีรายการเปิดขายที่ฝังไว้ในไฟล์โมเดล

## การใช้งาน

1. เปิด `/booking` เลือกรอบเรือ หรือเปิด `/booking-preview` สำหรับข้อมูลตัวอย่าง
2. เลือกชั้นและโหมดรายเก้าอี้ จากนั้นกด **เรือ 3D**
3. หมุน/ซูมเพื่อดูเรือ กด **ดูโต๊ะนี้** เพื่อขยายโต๊ะที่สนใจ เลือกเก้าอี้ หรือใช้รายการปุ่มเก้าอี้ที่มีชื่อกำกับใต้ภาพ
4. ตรวจรหัสเก้าอี้และยอดรวมในสรุปการจอง ก่อนเลือกรายการเสริมและยืนยันตามขั้นตอนเดิม

สามารถสลับกลับ **ผังละเอียด** และ **รายการโต๊ะ** ได้โดยเก็บการเลือกไว้ หากเครื่องไม่รองรับ WebGL หรือไฟล์โมเดลโหลดไม่สำเร็จ ให้ใช้ผังเดิมได้

## ความถูกต้องของข้อมูล

- ความจุดาดฟ้า **250 คน** เป็นข้อมูลที่ผู้ใช้ยืนยัน ไม่ใช่คำสั่งให้สร้างเก้าอี้ขาย 250 ตำแหน่ง
- รูปลักษณ์ภายนอกอ้างอิงภาพเรือจริง: ตัวเรือสีขาว/แชมเปญ หน้าต่างแนวยาว เส้นไฟสีฟ้า ดาดฟ้าเปิดโล่งและส่วนมีหลังคา
- สัดส่วนทำงานประมาณ **40 × 10 เมตร** ใช้เพื่อสร้างภาพเท่านั้น **ยังไม่ใช่ขนาดเรือที่วัดจริง** ความสูง ตำแหน่งบันได เวที และอุปกรณ์ต่าง ๆ ยังต้องเทียบกับแบบเรือจริงก่อนใช้รับรองตำแหน่งขาย
- ผังจองเดิมเป็นแหล่งข้อมูลตำแหน่งโต๊ะ รายการตัวอย่างยังเป็นรายการตัวอย่าง การเปลี่ยนมุมมองไม่เผยแพร่รอบเรือหรือแก้ราคา
- รายละเอียดและที่มาของข้อมูลอยู่ใน [เอกสารอ้างอิง](unicorn-cruise-reference-th.md) ข้อมูลตารางเวลา/ราคาในเว็บภายนอกไม่ถูกนำมาสร้างรอบเปิดขายอัตโนมัติ

## ไฟล์และการสร้างใหม่

- ต้นฉบับแก้ไขใน Blender: `assets/unicorn/unicorn-cruise.blend`
- สคริปต์สร้าง: `scripts/blender/build_unicorn.py`
- ไฟล์สำหรับเว็บ: `apps/web/public/models/unicorn/unicorn-{exterior,upper,lower}.glb`
- สถิติและข้อตกลงพิกัด: `apps/web/public/models/unicorn/manifest.json`
- หน้าเว็บ: `apps/web/src/components/cruise/UnicornBooking3D.tsx`

สร้างใน Blender background แบบแยกจาก scene ที่ผู้ใช้กำลังเปิดอยู่:

```powershell
& 'D:\blender\blender.exe' -b --factory-startup --python-exit-code 1 -P scripts/blender/build_unicorn.py
& 'D:\blender\blender.exe' -b --factory-startup --python-exit-code 1 -P scripts/blender/verify_unicorn.py
```

สคริปต์ตั้งฉากใหม่และเขียนทับเฉพาะผลลัพธ์ของโมเดลนี้ ควรสำรอง `.blend` ก่อนรันหากแก้ต้นฉบับด้วยมือ ไม่รันสคริปต์สร้างนี้ภายในงาน Blender อื่นที่ยังไม่ได้บันทึก

## ข้อตกลงพิกัดและสถานะจอง

Blender ใช้ Z เป็นแกนขึ้น และ export glTF เป็น Y ขึ้น หัวเรืออยู่แกน X ติดลบ พื้นที่วางเก้าอี้ชั้นบนอยู่ glTF Y = 5.25 และชั้นล่าง Y = 2.55

ตำแหน่งโต๊ะจากผังเดิมแปลงเป็น `x = (table.x - 500) × 0.04`, `z = (table.y - 290) × 0.018` เก้าอี้ใช้หมายเลขและการเรียงชุดเดียวกับผัง 2D รหัสเช่น `U01:2` ถูกส่งผ่าน callback การเลือกเดิม ระบบเซิร์ฟเวอร์ยังเป็นผู้ตัดสินราคา สิทธิ์ การล็อกที่นั่ง และการรับรายการจอง

ไฟล์ cutaway ไม่มีโต๊ะ/เก้าอี้สำหรับขายอยู่ภายใน หน้าเว็บสร้างโต๊ะจาก catalogue ของรอบที่เลือก ส่วนเฟอร์นิเจอร์ในโมเดลภายนอกเป็นองค์ประกอบภาพและกดจองไม่ได้

## การตรวจสอบ

ใช้ Blender Agent Skills สำหรับการสร้าง การส่งออก และ asset QA ตรวจรูปทรงจากหลายมุม พร้อมตรวจไฟล์ GLB หลังนำกลับเข้า Blender

ชุดทดสอบหน้าเว็บที่เกี่ยวข้อง:

```powershell
$env:TEST_BASE_URL = 'http://localhost:3000'
npx playwright test tests/unicorn-booking-3d.spec.ts tests/unicorn-live-booking.spec.ts tests/default-chair-selection.spec.ts tests/individual-chairs.spec.ts --workers=1 --reporter=list
npm run typecheck
npm run build
```

ชุดทดสอบ API fixture ยืนยันการเชื่อม UI กับสัญญา API โดยใช้ข้อมูลจำลอง ไม่ถือเป็นการชำระเงินจริงหรือยืนยันการได้รับอีเมลจริง การทดสอบระบบจองจริงต้องทำในฐานข้อมูลทดสอบที่แยกไว้ตาม README
