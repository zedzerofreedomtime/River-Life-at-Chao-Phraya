# UNICORN CRUISE — ข้อมูลอ้างอิงสำหรับโมเดลเรือและระบบเลือกที่นั่ง

ตรวจข้อมูลวันที่ **3 พฤศจิกายน 2026** (Asia/Bangkok) จากภาพใน repository, ภาพที่ผู้ใช้ส่ง และหน้าเว็บสาธารณะ รายงานนี้เป็นข้อมูลประกอบการออกแบบ ไม่ใช่แบบวัดเรือหรือเอกสารอนุมัติการเปิดขาย

## ข้อสรุปที่นำไปใช้ได้

- ใช้เรือ **UNICORN CRUISE เพียงลำเดียว** ตามขอบเขต River Life ที่ผู้ใช้ยืนยัน
- ผู้ใช้ยืนยัน **ความจุดาดฟ้า 250 คน** ให้เก็บเป็นความจุที่ได้รับแจ้ง ไม่ตีความเป็นพิกัดเก้าอี้ 250 ตัวจากภาพ
- ภาพและเอกสารที่ตรวจสอดคล้องกันว่าเรือมี **2 ชั้น**: ห้องอาหารปรับอากาศชั้นล่าง และดาดฟ้าชั้นบน ซึ่งมีทั้งพื้นที่กลางแจ้งและส่วนมีหลังคา
- ใช้ลักษณะภายนอกจริงเป็นหลัก: ตัวเรือขาว/เงิน หัวเรือลู่ ห้องขับยกด้านหน้า กระจกยาว ไฟสีฟ้า cyan โครงหลังคาดาดฟ้าท้าย และเครื่องหมายยูนิคอร์นข้างหัวเรือ
- จำนวนโต๊ะ รหัสเก้าอี้ และตำแหน่งที่เปิดขายต้องมาจากข้อมูลรอบเรือในระบบ โมเดลตกแต่งไม่ใช่แหล่งกำหนดราคา สถานะว่าง หรือความจุที่เปิดขาย
- วันขายจริงยังรอยืนยันตามบทสนทนา ไม่เพิ่มวันเดินทางหรือเปิดรอบขายจากผลค้นเว็บ

## ข้อกำหนดเชื่อมโมเดลกับการจอง

1. ใช้ `sailing_id` + รหัสที่นั่งของระบบ เช่น `U01:1` เป็นตัวระบุการจอง ห้ามใช้ชื่อ mesh หรือตำแหน่งคลิกเป็นราคา/สิทธิ์จอง
2. ผูกเก้าอี้ที่เลือกใน 3D กับข้อมูลเดียวกับผัง 2D: เลือก/ยกเลิก 1 ตัว, ว่าง/ไม่ว่าง, ชั้น, โต๊ะ, สรุปราคา และตั๋วต้องตรงกัน
3. แยก mesh ตกแต่งที่นั่งกับจุดเลือกซื้อ หากโต๊ะไม่มีพิกัดที่รองรับ ต้องไม่แอบแสดงตำแหน่งปลอมว่าเป็นตำแหน่งจริง
4. สถานะและราคาต้องมาจาก API; server ตรวจความว่างและรายการซ้ำตามระบบเดิม การระบายสีใน viewer ไม่ใช่การล็อกเก้าอี้
5. โมเดลควรแยก hull, lower deck, upper deck, canopy, furniture และจุดบริการ เพื่อสลับชั้น/ซ่อนหลังคาโดยไม่ซ่อนสถานะเก้าอี้
6. คงผัง 2D และรายการที่นั่งเป็นทางเลือกสำหรับมือถือ เครื่องที่เปิด WebGL ไม่ได้ คีย์บอร์ด และเครื่องอ่านหน้าจอ
7. ไม่มีการเพิ่มเก้าอี้ขาย 250 ตัวหรือเปลี่ยนจำนวนในฐานข้อมูลด้วยงานโมเดลนี้ ต้องเปิดขายเฉพาะเก้าอี้ที่ผู้จัดมีพิกัดและอนุมัติใช้งานแล้ว
8. หมายเหตุสั้นที่เหมาะกับหน้าจอ: “โมเดลประกอบการเลือกที่นั่ง ตำแหน่งตามผังของรอบที่เลือก” และในโหมดตัวอย่างต้องคงข้อความว่ายังไม่เปิดขาย

## สิ่งที่ต้องยืนยันก่อนเปิดขายจริง

- วันและเวลาใช้งานเรือของ River Life, ท่า, เวลาเช็กอินและขึ้นเรือ
- ผังเก้าอี้ของงานที่เลือกจริง พร้อมการจัดเลขและตำแหน่งเสา/บันได/จุดบริการ
- ความจุที่ได้รับอนุญาตตามรูปแบบจัดงาน รวมเจ้าหน้าที่และส่วนที่ไม่เปิดขายตามที่ผู้ดูแลเรือกำหนด
- ราคาต่อเก้าอี้/ทั้งโต๊ะ เมนูเสริม ราคา ปริมาณจำหน่าย และเงื่อนไขแบ่งโต๊ะกับผู้ร่วมทางอื่น
- การย้ายที่นั่งเมื่อฝนตก การเปลี่ยนรอบ/คืนเงิน และนโยบายเด็ก

งานค้นครั้งนี้ไม่ได้เปลี่ยนราคา จำนวนเก้าอี้ รอบเรือ หรือฐานข้อมูล และไม่ได้รับรองความถูกต้องเชิงวิศวกรรมของโมเดล 3D
